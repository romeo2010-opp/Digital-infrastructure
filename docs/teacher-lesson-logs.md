# Teacher Lesson Logs

Teacher Lesson Logs record what was actually taught, separate from the syllabus and term plan.

## Workflow

1. Open `Teacher Lesson Log` from the SmartLink Schools sidebar or the dashboard learning view.
2. Select the class and subject. SmartLink suggests assignments, recent unfinished topics, and the current term-plan topic.
3. Select the approved syllabus topic, subtopics, and optional learning objectives.
4. Record coverage, understanding, observed difficulty, notes, misconceptions, homework, and the next lesson action.
5. Save as draft or finalize.

Draft, reopened, and cancelled logs do not influence Daily Drills. Only finalized lesson logs are eligible.

## Permissions

Teachers can log only assigned class and subject combinations. School owners and headteachers can review all logs and reopen finalized logs when correction is needed.

## Audit Trail

Create, update, finalize, reopen, and cancel events are stored in `lesson_log_audit_events`.
